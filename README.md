This repository includes the scripts and data needed to analyze the air temperature impacts of Raleigh's cool pavement rejuvenation treatments using data from a network of 62 Kestrel sensors installed in the city

Notes on Data: 
- Raw sensor data and files that were too large to be stored on GitHub are available on DDL's Google Drive: https://drive.google.com/drive/folders/1KbgNDfDNsRjyUDiyf6zIJ3blXnI8oEpa?usp=sharing.

Notes on Code: 
- Scripts 01-03 were used to identify sensor installation locations in summer 2025 and do not need to be rerun or updated.
- Script 04 is not included here. A separate 04 cleaning R script was used for basic data checks and cleaning for each weekly/biweekly period of data collection during summer 2025, available on the GDrive: https://drive.google.com/drive/folders/1KbgNDfDNsRjyUDiyf6zIJ3blXnI8oEpa?usp=sharing
- Only Scripts 05, 06(a,b,c) need to be modified to update the results of the impact evaluation with new data collected in 2026.
- Script 07 is optional to be updated with 2026 treatment streets and updated variables, if desired.
